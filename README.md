# MyShop — E-Commerce Platform

A full-stack store: product listing with search/filters, cart with quantity management,
Stripe checkout (test mode), and order history with status tracking.

Stack: **Next.js 14** (App Router) · **PostgreSQL** · **Prisma** · **Stripe**

See the chat guide for the full step-by-step walkthrough (install Node, get a free
database, get Stripe test keys, run locally, push to GitHub, deploy to Vercel).
